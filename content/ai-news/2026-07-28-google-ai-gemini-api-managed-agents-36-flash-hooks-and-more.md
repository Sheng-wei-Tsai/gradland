## What was announced

Google AI has announced new capabilities for Managed Agents in the Gemini API, including defaulting to Gemini 3.6 Flash, new environment hooks for blocking, linting, or auditing tool calls, budget controls, scheduled triggers, and free tier access.

## Why it matters

Developers can now build more reliable and production-ready agents with the new default to Gemini 3.6 Flash. The addition of environment hooks provides more control over tool calls, while budget controls and scheduled triggers offer better management of resources and workflows. Free tier access makes it easier for developers to experiment and test new features.

## Key takeaways

- Managed Agents in Gemini API now default to Gemini 3.6 Flash, improving performance and reliability.
- New environment hooks allow developers to block, lint, or audit tool calls, enhancing security and code quality.
- Budget controls and scheduled triggers provide better resource management and workflow automation.
